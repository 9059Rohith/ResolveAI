# Citations and assistance disclosure

- Original dataset: [Thought Vector, Customer Support on Twitter](https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter), used under CC BY-NC-SA 4.0. Raw data is excluded from Git.
- Dataset license confirmation: [ASAPP dialog-intent-induction data license](https://github.com/asappresearch/dialog-intent-induction/blob/master/data/LICENSE).
- Structured output request shape: [OpenAI Responses API structured outputs](https://platform.openai.com/docs/api-reference/responses-streaming).
- Chroma distance configuration: [Chroma collections documentation](https://cookbook.chromadb.dev/core/collections/); text vectors use cosine space rather than Chroma's L2 default.
- Model price used in per-request estimates: [OpenAI GPT-4.1 mini model page](https://developers.openai.com/api/docs/models/gpt-4.1-mini), $0.40/M input and $1.60/M output tokens when checked 2026-09-10.
- Metrics use scikit-learn's documented implementations of macro-F1, confusion matrix, precision/recall, Pearson correlation through NumPy, and quadratic-weighted Cohen's kappa.

The application, tests, documentation, prompt templates, and taxonomy interpretation were produced with OpenAI Codex assistance under the applicant's direction. The applicant must review and be able to explain every part before submission. Human labels and human judge scores are intentionally never generated by the coding assistant.
